卅月 HDR

Perfect HDR, Awakened in Your Browser.

基于 WebGPU 的 Chrome 扩展，实时提升网页视频与图片的 HDR 观感。全部处理在本地 GPU 完成，不收集、不上传任何数据。

WebGPU Chrome 116+ MIT License 100% 本地处理

功能

实时 HDR 增强

GPU 上逐帧色调映射，支持 BT.2446a 标准曲线与自定义幂函数。

双层合成

分离低频亮度与高频细节，压高光时保留局部对比。

HDR 源智能处理

PQ / HLG 视频可接管增强，也可原样跳过交给系统播放。

去色带与锐化

多尺度自适应 deband 与 CAS 锐化，按需二选一。

取帧自适应

常规源零拷贝，补齐帧自动切快照规避顶部绿边。

诊断面板

一键复制取帧路径、绿边检测、HDR 路径等状态，问题可自证。

渲染管线

视频帧→ external texture / 2D snapshot
↓
色调映射（BT.2446a / 幂函数）
↓
双层合成（可选）
↓
高光上限 / 整体强度
↓
16float HDR 画布或8bit 画布

安装

  1. 克隆仓库：git clone https://github.com/skiqing/sanyue-hdr.git
  2. 打开 Chrome，进入 chrome://extensions
  3. 开启右上角的「开发者模式」
  4. 点击「加载已解压的扩展程序」，选择仓库根目录
  5. 点击工具栏图标打开弹窗，用顶部开关启用
